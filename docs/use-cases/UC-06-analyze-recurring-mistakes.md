# UC-06 — Analiza powtarzających się błędów

## Aktor

Gracz

## Cel

Poznanie błędów, które gracz regularnie popełnia, wraz z tym, co zmienić w następnej sesji.

## Powiązane wymagania

FR-11, FR-04, NFR-01

## Warunek wstępny

Gracz ma zarejestrowane sesje w wybranym okresie.

## Scenariusz podstawowy

1. Gracz prosi o analizę wybranego okresu, np. „Jakie błędy powtarzam w ostatnim tygodniu?”.
2. System ustala ważne okrążenia z tego okresu, które podlegają analizie.
3. System wyszukuje błędy powtarzające się.
4. System przedstawia zestawienie błędów, każdy z miejscem na torze, przyczyną i tym, co zmienić.

## Scenariusze alternatywne

- **2a. Brak sesji w wybranym okresie lub za mało ważnych okrążeń w wybranym okresie:** System informuje gracza, że nie ma zarejestrowanych sesji w tym okresie lub ważnych okrążeń jest za mało.
- **2b. Okres obejmuje zbyt wiele okrążeń:** System informuje gracza o limicie analizowanych okrążeń i prosi o zawężenie okresu.
- **3a. Brak błędów powtarzających się:** System informuje gracza, że w wybranym okresie nie znaleziono błędów powtarzających się.
