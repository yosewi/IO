# UC-04 — Pytanie o styl jazdy

## Aktor

Gracz

## Cel

Uzyskanie odpowiedzi na pytanie o własną jazdę w wybranej sesji, okrążeniu lub sektorze.

## Powiązane wymagania

FR-05, NFR-02

## Warunek wstępny

Gracz ma zarejestrowaną co najmniej jedną sesję.

## Scenariusz podstawowy

1. Gracz zadaje pytanie w języku naturalnym, np. „Dlaczego w drugim sektorze tracę tyle czasu?”.
2. System rozpoznaje, której sesji, okrążenia lub sektora dotyczy pytanie.
3. System analizuje telemetrię z tego zakresu.
4. System odpowiada na pytanie gracza.

## Scenariusze alternatywne

- **2a. Nie wiadomo, czego dotyczy pytanie:** System prosi gracza o doprecyzowanie, której sesji, okrążenia lub sektora dotyczy pytanie.
- **3a. Brak danych dla wskazanego zakresu:** System informuje gracza, że nie posiada danych dla wskazanej sesji, okrążenia lub sektora.
