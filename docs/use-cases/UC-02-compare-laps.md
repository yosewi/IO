# UC-02 — Porównanie dwóch okrążeń

## Aktor

Gracz

## Cel

Dowiedzenie się, gdzie i dlaczego jedno okrążenie było wolniejsze od drugiego.

## Powiązane wymagania

FR-02, FR-03, FR-04

## Warunek wstępny

Gracz ma zarejestrowane co najmniej dwa okrążenia na tym samym torze.

## Scenariusz podstawowy

1. Gracz wybiera dwa okrążenia do porównania, np. okrążenie 5 i okrążenie 12 z dzisiejszej sesji.
2. System porównuje okrążenia i wylicza stratę czasu na każdym zakręcie.
3. System wskazuje zakręty, na których gracz stracił najwięcej czasu.
4. System identyfikuje przyczynę straty czasu na tych zakrętach.
5. System prezentuje wyniki porównania wraz ze wskazówkami, co zmienić.

## Scenariusze alternatywne

- **1a. Wybrano okrążenie nieważne:** System informuje gracza, że okrążenie jest nieważne, i prosi o potwierdzenie wyboru lub wybranie innego okrążenia.
- **1b. Wybrano okrążenia z różnych torów:** System informuje gracza, że można porównać tylko okrążenia z tego samego toru.
- **3a. Brak istotnej straty czasu:** System informuje gracza, że okrążenia nie różnią się istotnie na żadnym zakręcie.
- **4a. Nie można ustalić przyczyny:** System prezentuje stratę czasu na zakręcie i informuje gracza, że nie udało się ustalić jej przyczyny.
