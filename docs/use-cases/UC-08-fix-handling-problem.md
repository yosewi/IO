# UC-08 — Korekta ustawień na podstawie problemu z prowadzeniem

## Aktor

Gracz

## Cel

Otrzymanie zmian w ustawieniach samochodu, które rozwiążą opisany problem z prowadzeniem.

## Powiązane wymagania

FR-07, NFR-02

## Warunek wstępny

System posiada informacje o ustawieniach samochodu, które gracz może zmieniać.

## Scenariusz podstawowy

1. Gracz opisuje problem z prowadzeniem, np. „Na wyjściu z wolnych zakrętów ucieka mi tył”.
2. System rozpoznaje rodzaj problemu, np. utratę przyczepności, problemy ze skręcaniem lub niewłaściwą pracę hamulców.
3. System dobiera zmiany w ustawieniach samochodu.
4. System prezentuje zalecane zmiany i wyjaśnia, jak wpłyną na prowadzenie.

## Scenariusze alternatywne

- **2a. Opis problemu jest zbyt ogólny:** System prosi gracza o doprecyzowanie, w którym miejscu toru i w jakiej sytuacji występuje problem.
- **2b. Problem nie wynika z ustawień samochodu:** System informuje gracza, że przyczyną jest sposób jazdy, i wskazuje, co zmienić w jeździe.
